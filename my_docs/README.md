# Documentation notes

This folder explains the standalone flow scripts and how the OpenLane-style
Yosys flow differs from the my_tpu Yosys flow.

- 02_picocore.md: PicoRV32 CPU core deep dive.
- 03_uart_peripheral.md: UART peripheral deep dive for SoC documentation and placement interviews.
- 04_gpio_peripheral.md: GPIO peripheral deep dive for SoC documentation and placement interviews.
- 05_timer_peripheral.md: Timer peripheral deep dive for SoC documentation and placement interviews.
- 06_spi_peripheral.md: SPI master peripheral deep dive for SoC documentation and placement interviews.
- 07_flash_peripheral.md: QSPI flash controller deep dive for SoC documentation and placement interviews.
- 08_debug_peripheral.md: debug module and JTAG peripheral deep dive for SoC documentation and placement interviews.
- yosys_openlane_vs_my_tpu.md: differences and intent.
- script_reference.md: basic explanation of each bash and Yosys script.
- yosys_scripts_deep_dive.md: in-depth from-scratch explanation of the Yosys scripts and pass flow.
